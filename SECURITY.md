# Security Policy

## Supported versions

Security fixes target the latest `main` branch and the latest published release (when releases exist).

## Reporting a vulnerability

**Use [GitHub Security Advisories](https://github.com/newtosh/nitpub/security/advisories/new) only.**

Do **not** file a public GitHub Issue for a vulnerability. Do not post exploit details in Discussions, pull requests, or other public channels.

If Advisories are unavailable for any reason, wait until they are enabled on this repository rather than disclosing publicly.

We will acknowledge private reports through the Advisories workflow and coordinate a fix and disclosure timing there.
