# Support

## Getting help

For install questions, bugs that are **not** security vulnerabilities, and feature discussion, open a [GitHub Issue](https://github.com/newtosh/nitpub/issues).

## Security vulnerabilities

Do **not** file public Issues for vulnerabilities.

Report them privately via [GitHub Security Advisories](https://github.com/newtosh/nitpub/security/advisories/new) as described in [SECURITY.md](SECURITY.md).
