# nitpub docs

**ActivityPub blog for notes and long-form articles on your own domain** — one Go binary on a small VPS, without running Mastodon.

This site is the **canonical install guide**. The [product site](https://www.nitpub.com/) covers the pitch; the [GitHub README](https://github.com/newtosh/nitpub) is a short hub.

## Start here

1. [Install (golden path)](/guide/install) — one-liner → first published note
2. [Federation](/guide/federation) — visible federated reply
3. [Analytics](/guide/analytics) — optional GoatCounter
4. [Updates](/guide/updates) — `nitpub update --apply`

Live demo: [nitpub.com](https://nitpub.com) (`@nit@nitpub.com`)

## Advanced / ops

Multi-instance, GoatCounter deep dive, and maintainer workflows live in the repo [`deploy/README.md`](https://github.com/newtosh/nitpub/blob/main/deploy/README.md).
