# About this demo

This is the public **nitpub** demo at [nitpub.com](https://nitpub.com) (`@nit@nitpub.com`).

It shows a minimal self-hosted ActivityPub blog: notes, articles, and federated replies — without running Mastodon.

- Product: [www.nitpub.com](https://www.nitpub.com/)
- Docs: [docs.nitpub.com](https://docs.nitpub.com/)
- Source: [github.com/newtosh/nitpub](https://github.com/newtosh/nitpub)
